# CLI reference

- `mailnotmilk serve` — MCP stdio
- `mailnotmilk install --all|--tool <name>`
- `mailnotmilk whoami`
- `mailnotmilk send -t TEXT [--to ID] [-r ROOM] [-f FROM]`
- `mailnotmilk inbox [-a ID] [-n N] [--read]`
- `mailnotmilk agents`
- `mailnotmilk status [ID] [--set idle|working|waiting]`
